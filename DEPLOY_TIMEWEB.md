# Выкладка «Ресурса» на Timeweb Cloud (App Platform)

Сайт и сервер собраны в один контейнер (`Dockerfile` в корне репозитория) — на
Timeweb создаётся **одно приложение**. Данные хранятся в управляемой базе PostgreSQL.

Время: ~15 минут. Всё делается мышкой в панели Timeweb, без терминала.

---

## Шаг 1. Аккаунт

1. Зайти на https://timeweb.cloud и зарегистрироваться / войти.
2. Пополнить баланс на минимальную сумму (App Platform — от нескольких рублей,
   база — отдельный недорогой тариф).

## Шаг 2. База данных (чтобы регистрации не пропадали)

1. В панели: **Облачная база данных** → **Создать**.
2. Тип: **PostgreSQL**, самый младший тариф.
3. После создания открыть базу и скопировать **строку подключения** — она
   выглядит примерно так:
   `postgresql://user:password@host:5432/dbname`
   Сохрани её — понадобится на шаге 4.

## Шаг 3. Создать приложение из GitHub

1. В панели: **Apps (App Platform)** → **Создать приложение**.
2. Источник: **Git / GitHub** → авторизовать Timeweb в GitHub (откроется окно
   GitHub, нажать Authorize).
3. Выбрать репозиторий **Elenafromsochi/Resource**.
4. Ветка: **claude/resurs-service-prototype-txouaw**.
5. Тип сборки: **Dockerfile**. Путь к Dockerfile: `Dockerfile` (в корне).
6. Порт приложения: **8000**.

## Шаг 4. Переменные окружения

В настройках приложения добавить переменные:

| Имя                 | Значение                                            |
|---------------------|-----------------------------------------------------|
| `DATABASE_URL`      | строка подключения из шага 2                         |
| `JWT_SECRET`        | любая длинная случайная строка (например, 30+ знаков)|
| `ANTHROPIC_API_KEY` | *(необязательно)* ключ Anthropic для умного ИИ       |

Без `ANTHROPIC_API_KEY` ИИ-помощник работает в офлайн-режиме — это нормально.

## Шаг 5. Деплой

1. Нажать **Создать / Deploy**. Timeweb сам соберёт образ (сборка ~3–5 минут).
2. После сборки приложение получит адрес вида `https://xxxxx.twc1.net`.
3. Открыть этот адрес — это и есть рабочий сайт «Ресурс». Регистрируйся и пользуйся.

## Обновления

Любой новый коммит в ветку → Timeweb пересобирает и обновляет сайт автоматически
(CI/CD). Откат на прошлую версию — одной кнопкой в панели.

## Свой домен (по желанию)

В настройках приложения → **Домены** можно привязать свой домен вместо `*.twc1.net`.

---

### Если что-то пошло не так
- Сборка падает → открой **Логи** приложения в панели, пришли мне последние строки.
- Сайт открылся, но «не удаётся войти/зарегистрироваться» → почти всегда неверная
  `DATABASE_URL`. Проверь, что скопирована целиком.
