# Ресурс · Тренер

Визуальный прототип приложения для персонального фитнес-тренера и его клиентов —
в формате сайта, оформленного как мобильное приложение.

У тренера и у клиента **свои интерфейсы**, между ними можно мгновенно
переключаться демо-кнопкой в шапке (реального входа в прототипе нет).

## Что умеет

**Интерфейс тренера** 🏋️‍♀️
- **Обзор** — статистика, ближайшие тренировки всех клиентов, последние отзывы.
- **Клиенты** — список клиентов, план каждого; можно добавлять и удалять
  тренировки (упражнения подставляются из шаблонов «Ноги / Верх / Общая»).
- **Календарь** — все тренировки клиентов с цветовой разметкой по типу и статусу.
- **Отзывы** — лента отзывов клиентов о пройденных тренировках; новые подсвечены.
- **Чат** — переписка с выбранным клиентом.

**Интерфейс клиента** 🙋
- **Главная** — прогресс, ближайшая тренировка, напоминание.
- **План** — список тренировок; можно отмечать выполненные упражнения,
  завершать тренировку и **оставлять отзыв** (оценка, нагрузка, самочувствие,
  комментарий) — он тут же виден тренеру.
- **Календарь** — свои тренировки.
- **Чат** — переписка с тренером.

**Сквозные функции**
- **Напоминания и уведомления** — колокольчик в шапке: ближайшие тренировки,
  новые отзывы, непрочитанные сообщения. Всё внутри приложения.
- **Календарь тренировок** — помесячный, с точками-индикаторами.
- **Чат** — внутри приложения, отдельная ветка с каждым клиентом.

Данные упражнений взяты из плана клиента (фото): три блока — **Ноги**, **Верх**,
**Общая** — с реальными упражнениями и схемами подходов (10×3, 18-16-14 и т.д.).

## Стек и данные

- **Frontend:** Vue 3 + Vite. Никакого сервера прототипу не нужно.
- **Хранилище:** всё живёт в браузере (`localStorage`), поэтому демо переживает
  перезагрузку. Кнопка «↺ Сбросить демо-данные» — в панели уведомлений.

## Запуск

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173
```

Сборка статики: `npm run build` → каталог `frontend/dist`.

## Про бэкенд

В репозитории остаётся заготовка бэкенда (`backend/`, FastAPI + авторизация) от
предыдущего этапа. Текущий прототип фитнес-приложения — **чисто фронтовый** и от
бэкенда не зависит. Его можно подключить позже, когда понадобятся настоящие
аккаунты, роли и общий доступ к данным между устройствами.
