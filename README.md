# Ресурс

Прототип. Сейчас в нём ровно два экрана:

1. **Регистрация / вход** — по email и паролю.
2. **Личный кабинет с ИИ-помощником** — пользователь рассказывает о себе свободным
   текстом, ИИ раскладывает рассказ по полям профиля (имя, род занятий, город,
   навыки, интересы, цели, о себе) и подсказывает, чего ещё не хватает. Черновик
   можно поправить вручную и сохранить.

## Стек

- **Backend:** FastAPI + SQLAlchemy. БД по умолчанию SQLite (локально/тесты),
  в Docker — PostgreSQL.
- **Frontend:** Vue 3 + Vite (один сайт).
- Авторизация: регистрация по email/паролю, JWT.

## ИИ-помощник

Реализован через подключаемый провайдер (`backend/app/ai.py`):

- **Claude** — если задан `ANTHROPIC_API_KEY`, разбор рассказа делает реальный LLM.
- **Офлайн** — если ключа нет, работает эвристический помощник: извлекает поля по
  ключевым словам и задаёт уточняющие вопросы. Прототип запускается без ключей.

Интерфейс один и тот же — клиент не знает, какой провайдер сработал (видит лишь
метку `provider`).

## Запуск

```bash
cp .env.example .env
docker compose up --build
```

- Сайт: http://localhost:5173
- API: http://localhost:8000 (доки: http://localhost:8000/docs)

### Локально без Docker

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload     # БД — SQLite

pytest                            # тесты авторизации и ИИ-помощника
```

## API

| Метод | Путь                  | Назначение                                  |
|-------|-----------------------|---------------------------------------------|
| POST  | `/api/auth/register`  | регистрация (email, password) → токен       |
| POST  | `/api/auth/login`     | вход → токен                                |
| GET   | `/api/profile`        | профиль текущего пользователя               |
| PUT   | `/api/profile`        | сохранить поля профиля                      |
| POST  | `/api/profile/assist` | ИИ-черновик профиля из рассказа + вопросы   |
